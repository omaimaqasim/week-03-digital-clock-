
# ⏰ Week-03 Digital Clock  

A simple **Digital Clock** built using HTML, CSS, and JavaScript. This project displays the current time in real-time and updates every second.  

---

## 📌 Features
- Displays **hours, minutes, and seconds**.  
- Time updates automatically every second.  
- Always shows **two digits** (e.g., `09:05:07`).  
- Responsive and centered layout with clean design.  

---

## 🛠️ Technologies Used
- **HTML** → Provides structure.  
- **CSS** → Adds styling and layout.  
- **JavaScript** → Handles logic for real-time clock updates.  

---

## 🎯 Learning Objectives
- Practice separating **HTML, CSS, and JS** into different files.  
- Learn how to use JavaScript’s **`Date()` object**.  
- Understand **`setInterval()`** for live updates.  
- Apply **string formatting** using `String.padStart()`.
